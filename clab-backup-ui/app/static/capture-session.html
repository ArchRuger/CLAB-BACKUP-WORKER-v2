How to save a capture

In Wireshark, stop the capture, choose File → Save As, pick the /pcaps folder and type the full file name ending in .pcapng (Wireshark on the VM does not add it for you). Then click Download saved captures.

Ending the session deletes its files. If you close this tab the session stays available for 15 minutes; every session ends after 2 hours.

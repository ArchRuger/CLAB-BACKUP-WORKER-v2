Browser Wireshark setup

Wireshark runs on the lab VM and opens in your browser. No workstation plugin, VNC client or capture-port tunnel is needed.

1. Install the optional VM services

From the complete 1.23.1 source checkout:

sudo bash deploy/setup-capture.sh
bash deploy/install.sh

Setup starts Edgeshark and the browser session service and updates capture settings while preserving unrelated configuration. Download active browser captures before upgrading: restarting the service removes temporary sessions.

If the manager already runs 1.23.1, apply the settings with:

sudo docker compose --env-file clab-backup-ui/.env \
  -f clab-backup-ui/compose.yml up -d --no-deps backup-ui

The bundled stack needs free localhost ports 5001 and 5801. Setup does not remove another tool's Edgeshark installation; resolve conflicts first. Keep the manager on a trusted management network or use an authenticated HTTPS reverse proxy with WebSocket support.

2. Capture in your browser

Open Capture packets, a node's Capture action, or a topology link. Choose a live target and Linux interfaces, then Start browser capture → Open Wireshark in browser. On a link choose either endpoint. All host targets includes host NICs, bridges and other namespaces.

3. Save, download and end

Stop capturing in Wireshark, then use File → Save As under /pcaps. Click Download saved captures (.tar) and extract the archive to get your PCAPNG files. End session deletes the container and its temporary files.

Four sessions can run at once. Closing a viewer leaves it available for up to 15 minutes under Sessions in this browser. Every session expires after two hours. The capture folder holds 256 MiB. Save and download before expiry; files do not enter backup or Git history.

Troubleshooting

  • Disabled/unavailable: run setup, recreate the manager and check service logs.
  • Viewer disconnected: reconnect to the existing session; capture may still be running.
  • Session not found: it may have expired or belong to another browser profile.
  • No matching interface: use All host targets and select its Linux name; NOS aliases can differ.
  • Download reports no saved captures: stop the capture in Wireshark, use File → Save As under /pcaps, then download again; the archive only holds that folder.
  • No packets: check the endpoint and generate traffic. DOWN interfaces, stopped containers and traffic hidden inside nested VMs remain outside exposed Linux interfaces.
sudo docker compose --env-file clab-backup-ui/.env -f deploy/compose.capture.yml ps

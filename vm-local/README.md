# VM-only material preserved before the 2026-10-02 snapshot rollback

This branch (`claude/vm-local-preservation`) is a snapshot of every file that lived only on the
development VM `clab-llm-dev2` and mattered to the project's development. It is **not for merging**:
the files at repository paths (`.claude/…`, the three `CLAB_*.md` prompts) are on this branch so that
checking it out restores the VM's working tree exactly; the maintainer never committed them on the
feature branches on purpose. Everything that lived outside the checkout is under `vm-local/`.

Base commit: `aec684e` on `claude/ui-ux-changes-2` (release 1.30.57). Taken on 2026-10-02.

## Restore recipe after a rollback

```bash
cd ~/projects/clab-manager && git fetch origin
git switch claude/vm-local-preservation          # or: git worktree add ../preserve claude/vm-local-preservation
# repository-path files back into the main checkout's working tree (do not commit them there):
git switch claude/technical-audit                # whatever branch you work on
git checkout claude/vm-local-preservation -- .claude CLAB_Netlab_Integration_Claude_Code_Prompt_v2.md CLAB_Netlab_Relentless_UI_UX_QA_Campaign_v2.md CLAB_Single_Device_Restart_Addendum.md
git restore --staged .claude CLAB_*.md           # keep them uncommitted, as before
# home-level files:
P=vm-local; git checkout claude/vm-local-preservation -- "$P"; git restore --staged "$P"
mkdir -p ~/.claude/projects/-home-clabllm-projects-clab-manager/memory ~/.claude/projects/-home-clabllm/memory ~/.claude/projects/-home-clabllm-projects-AF-LEARNING-LABS/memory
cp $P/claude-memory/clab-manager/*.md ~/.claude/projects/-home-clabllm-projects-clab-manager/memory/
cp $P/claude-memory/home/*.md ~/.claude/projects/-home-clabllm/memory/
cp $P/claude-memory/AF-LEARNING-LABS/*.md ~/.claude/projects/-home-clabllm-projects-AF-LEARNING-LABS/memory/
cp $P/home/.claude/settings.json ~/.claude/settings.json
cp $P/home/setup_claude_ui_routing.py $P/home/AGENT-CONNECTION-GUIDE.md $P/home/AGENT-CONNECT.md ~/
mkdir -p ~/research ~/labs-src && cp -r $P/research/* ~/research/ && cp -r $P/validation-tools $P/ui-review $P/maintenance-audit-wip ~/ && cp -r $P/labs-src/* ~/labs-src/
rm -rf $P                                        # the copy in the working tree is no longer needed
gh auth login                                    # ArchRuger (product repo pushes) and pruger-dev (manager's save repos)
```

Then `claude` once in `~/projects/clab-manager` to log in again, and `python3 deploy/verify-release.py`
to confirm the checkout. The rest of the VM (Docker, containerlab, the manager container, the labs) is
installed from the repository as `docs/INSTALL.md` describes.

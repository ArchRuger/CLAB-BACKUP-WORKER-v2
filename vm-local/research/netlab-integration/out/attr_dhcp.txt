
You can use the following dhcp attributes:
==============================================================================

interface:
  client:
    default: bool
    ipv4: bool
    ipv6: bool
  server:
    _subtype: node_id
    type: list
  vrf: str
link:
  client:
    default: bool
    ipv4: bool
    ipv6: bool
  subnet:
    ipv4: bool
    ipv6: bool
node:
  server: bool
  vrf: bool

==============================================================================
See https://netlab.tools/dev/validation/ for more data type- and
attribute validation details.

## Open questions

- Bundle size and load time of a minimal editor page (React 19 + MUI 9 + React Flow + Monaco + ELK + MapLibre): no build was run, so not measured.
- Actual behaviour under the manager's CSP (script-src 'self', style-src 'self'): Emotion/MUI <style> injection and ajv.compile's new Function were reasoned from code, not executed in a browser; which exact CSP relaxations a dedicated page would need is undetermined.
- Whether/when 0.4.0 (slots, lifecycleActionsAvailable, viewerOptions, documentKey/invalidateCache stale detection) will be published to npm: the clone is shallow (one commit) and gives no release signal.
- In 0.3.2, can the deploy/destroy split-button and the 'geo' layout entry (external OSM tiles) be hidden without patching? No prop was found; at HEAD only lifecycleActionsAvailable covers the deploy menu, nothing covers geo.
- The 'rejected YAML save drops the user's Monaco draft' path (PaletteSection.tsx:662-674 + topologyHostCommands.ts:133-148) was derived from code only, not reproduced in the UI.
- Behaviour of TopologySessionCore with YAML anchors/aliases, ${ENV} placeholders, multi-document files or very large labs was not tested; every ack returns a full snapshot (all nodes, edges, annotations and both file texts), so latency over HTTP for big labs is unknown.
- Whether a manager-side FileSystemAdapter should pass the .tmp-/.bak- rename sequence through to the VM helper or virtualise it and perform one atomic write: this depends on the host_operations helper's rules (another agent's area); upstream gives no guidance beyond 'not crash-atomic'.
- How upstream's real backends (app-server / clab-api-server) detect external file changes and push topology-host:snapshot was outside this area and not traced.

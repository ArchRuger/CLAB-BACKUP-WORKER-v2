Whether 'must not touch the backend' binds a post-redesign feature is the maintainer's call; every CSP option needs an edit to clab-backup-ui/app/main.py and new tests.
- Whether the maintainer would accept script-src 'unsafe-eval', worker-src blob:, a Node build stage that runs on every user VM, or a multi-megabyte committed bundle cannot be answered from the repository; none has a precedent.
- Whether the VM helper's create action (new .yaml/.yml only, existing parent folder, no overwrite, no annotations file) would be widened for a builder is a security-sensitive host_operations.py question outside this area; without it a builder can only produce a new YAML, and node positions can only reach the manager through the annotations part of POST /api/lab-definitions or PUT /layout.
- Cache-Control: no-store applies to every static response; whether a large bundle would justify a per-path caching exception (another middleware change) was not decided.

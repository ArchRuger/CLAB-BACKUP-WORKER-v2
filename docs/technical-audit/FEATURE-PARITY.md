# Feature-preservation matrix

Written before the first deletion of the technical audit (2026-09-23, base `main` `b1ced1d`, release 1.30.38).
Every retained capability is listed with its entry points, the invariants that bind it, the stored-data and API
contracts it depends on, and the acceptance evidence that exists or is produced by this audit. The telemetry and
Grafana rows are marked **remove**: that removal is the one intentional product change of the audit. Evidence
classes: **unit** (Python and `node:test` suites), **fixture** (the fixture manager in a browser), **CI**, **live**
(the dev VM, its lab or a Git remote). The "Audit evidence" column is filled in as the work proceeds; a row with
only "baseline" has not been re-proven yet.

| R3 | Telemetry rows of the health check and the installer phase, the CI Grafana smoke test | `check_install.py`, `install-manager.py`, `start-manager.sh`, `.github/workflows/release-check.yml`, `deploy/telemetry/smoke.py` | **remove**; replaced by one health-check row that reports leftovers of the retired stack |
| R4 | Guides: `docs/TELEMETRY.md`, `docs/GRAFANA-MAP.md`, `deploy/TELEMETRY-THIRD-PARTY-NOTICES.md` | living documentation | **remove**; `docs/TELEMETRY.md` becomes a short retirement notice so existing links explain themselves |

Not removed although the word appears: React Flow inside the editor bundle (unrelated to Grafana's Flow panel), the
editor's own `exportGrafanaBundle` hook (the upstream editor's feature, stubbed and hidden), the `grpc`/`gnmi`
lines that belong to lab base configurations and the quick-start example configurations, the interface-naming rules
in `topology.py`, and every history record.

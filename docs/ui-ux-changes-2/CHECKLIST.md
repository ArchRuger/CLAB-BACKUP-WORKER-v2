# UI/UX changes 2: requirements checklist

The developer's email `Ui/Ux Changes 2` (2026-10-02, nine screenshots) walked a fresh install as a student would.
Each row quotes the requirement, names the release that carries it and its status. Status words:
**open**, **in progress**, **done (live)** = verified in a real browser against the installed manager on the dev VM,
**done (fixture)** = verified only against the fixture manager, **partly done**, **not done**. Evidence lives under
`evidence/` (sanitised screenshots and logs) and is indexed in `PICKUP.md`.

Outside the ten items, the email ends with "Make docker commands sudo less for the clab-manager. This will prevent errors".
That asks for a change to the security boundary (the manager deliberately has no Docker socket and no root; every host
action goes through the forced-command account and the sudoers helpers), so it was **not** implemented in this stream; the
final report asks the developer to decide.

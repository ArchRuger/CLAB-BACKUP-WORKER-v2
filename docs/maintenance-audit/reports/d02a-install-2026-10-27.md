## Overlap note (intended reader of each; not merged)

- QUICK-INSTALL: a person pasting commands, one ordered route, no explanation. Repeats the clock fix, the WinSCP sudoers
  block and the engineer-access command from INSTALL and FRESH-VM; kept because it must be self-contained.
- INSTALL: what the installer's menu, phases, upgrade, lock recovery and options do. Owns the installer behaviour; the other
  guides now point to its `--advanced` section instead of restating prompts (the table in FRESH-VM step 5 is the one remaining
  restatement, kept short).
- FRESH-VM-GUIDE-V2: a person starting before Ubuntu exists (Proxmox, Ubuntu, then the same route) plus recovery A-C. Owns the
  WinSCP admin-SFTP, VS Code and clock procedures that INSTALL and QUICK-INSTALL link to.
- STANDALONE-SETUP: the pieces one by one, migration from the old in-lab worker, prebuilt image, backup. Sections 1 and 4 repeat
  what the launcher does; now said so.
- HEALTH-CHECK, VM-CONNECTION, DEBUG-PANEL: one tool each; VM-CONNECTION duplicates `vm-connection.html` (served by the app;
  not mine, same content in places).

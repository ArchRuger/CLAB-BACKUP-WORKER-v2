# The student quick start after the redesign: what is out of date

`docs/student-quick-start/` is a dated record (guide revision 1, tested with manager release 1.30.35) and is not
edited. This file lists, step by step, what its steps say that the Git save and load redesign has changed, and what
the step is now, so that the next revision of the guide can be written from it. Every "now" is taken from the page's
own scripts (`save-header.js`, `load.js`, `save-drawers.js`, `git-places.js`, `status.js`) and from
[DESIGN.md](DESIGN.md); nothing here was run in a browser or on a VM. Rows marked *check live* rest on the design
or the code and were not seen working.

The file is `docs/student-quick-start/source/guide.md` (the PDF is built from it). Steps A1 to A4, B1 to B5,
B10's destroy, remove and clone actions and the Stop, Destroy, Remove reference are not affected.

## What changed in short

- There is no **Progress** tab. Saving and loading live in the lab header on every tab: the save chip, **Save** and
  **Load**.
- A save now holds the topology file and the map as well as the device configurations.
- There is no acknowledgement tick box, no **Review before uploading** dialog and no **Create checkpoint…** or **Set
  baseline…** menu. A save ends with one sentence and **Upload**, **Not now**, **See changes**.
- A lab can save into any folder, and *Apply to running lab…* is **Load**: choose a state, click the red **Load**.

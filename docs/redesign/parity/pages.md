# Parity map — module `pages` (SSH terminal, SSH/deploy workspace page, Grafana launcher, Debug panel)

Sources: `inventory/pages.md` (every row), `DESIGN-SPEC.md` §0–§5, `UX-AUDIT.md`, the page sources under `clab-backup-ui/app/static/` (`terminal.*`, `workspace.*`, `grafana.*`, `debug.*`), `tests/test_grafana_ui.js`, `tests/test_debug_ui.js`, `tests/test_operations_ui.js` (#8), `tests/test_readiness_ui.js` (#1, #5), `tests/test_download_ui.js` (#5), `app/diagnostics.py`, `app/node_services.py`, `app/grafana_control.py`, screenshots `33-workspace-page`, `34-terminal`, `30-debug`, `09-operation-history`.

Headline: the spec gives these four pages a **home** (Manager ▾ › Diagnostics, Manager ▾ › Deploy a new lab…, Tools › Open network dashboard, Tools/Topology › Open all CLIs, Device workspace › Open CLI) but says **nothing about the pages themselves** beyond "other pages keep their own headers" (§1.1) and "keep terminal.css separate but re-tokenised" (§3). Every student-facing string on `terminal.html`, `workspace.html`, `grafana.html` and `debug.html` is therefore unspecified, and several of those strings are exact-match test contracts. Nothing in this module is lost by the spec; the gaps are copy, one label collision, one navigation precedence rule, and one missing script include.

G3 `capture.disabled-gating` / `capture.provider-disabled` — tooltip names a removed label; Tools card has no disabled state (Telemetry card has one). Fix: tooltip M25; Tools card renderer reads `captureEnabled` (guarded `typeof`) or a new `captureStatusLine()` in capture.js; `#capture-open` never disabled.
G4 `capture.dialog` — spec gives no copy beyond the title. Fix: table §3 M1–M27; update the listed test assertions while keeping each behavioural claim; use "Capture traffic…" (ellipsis) on every dialog-opening button (drawer, context menu, technical row, Tools card) and "Packet capture…" only in Lab actions ▾.
G5 `capture.target-select` — option labels expose `(kind)` and "shares namespace with". Fix: M22; tests `:48,53`.
G6 `viewer.page` — absent from spec §4 file table and §3 CSS sections. Fix: add `capture-session.html/.js` to §4 with V1–V11, keep `#capture-screen{flex:1;min-height:0}`, `body.capture-viewer{height:100vh;overflow:hidden}`, `.capture-viewer-help[open]`, `?v=1.29.0` via `set-release.py`.
G7 `setup.page` — operator page linked from the student dialog. Fix: keep the path; retitle "Packet capture setup (administrators)"; add a lead "For students: open Tools › Packet capture in your lab. If it says packet capture is not set up, ask your instructor or administrator — the steps below are for them."; relabel button references to the new names ("Capture traffic", "Start capture → Open Wireshark", "Everything on the VM", "Your capture sessions"); living-doc rule of `verify_docs` applies; `?v=1.29.0`.
G8 `capture.css-hooks` — `.capture-dialog [hidden]{display:none!important}` is behaviour (`#capture-launch`, `#capture-more`). Fix: in the rewrite make the global `[hidden]{display:none!important}` win over `.button{display:inline-flex}` (e.g. `.button[hidden]` rule) and keep `.capture-dialog [hidden]`; add `[tabindex="0"]:focus-visible` for SVG wires.

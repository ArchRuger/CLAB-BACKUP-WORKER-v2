## Chunks as proposed by the synthesis

### 1. C01 juniper-device-support

Make juniper_vjunosrouter (n24l/juniper_vjunos-router:26.2R1.7) a first-class managed kind: default login, readiness, backup, Open CLI gating, builder template, download-name contract, aliases. Restore stays off. About 3 h. Offline unit tests, then one short live pass: a single vJunos-router node (about 5 GB) for login, readiness and a backup. No helper change.

Why this order: It is the only gap that blocks the campaign's own test image: without it the router cannot be logged in to, backed up or used by any later chunk's live check. It is data and tables (inventory, downloads, builder template), reviewed by risk-reviewer for the login-default rule, and low risk.

Rows: R035

### 2. C02 terminal-and-copy-ergonomics

Terminal toolbar (font size and zoom keys, copy selection or screen, clear, client-side export of screen and session text) and a copyText helper with Copy buttons on drawer facts and operation output. Plain JavaScript only; shell.js owns the clipboard code. About 2 h. Fixture manager and node:test; no live lab (one cEOS SSH session for a manual terminal look if a lab is already up).

Why this order: Quick, visible, near-zero risk and touches no helper or privileged path. It also supplies copyText that C03, C04, C09 reuse.

Rows: R025, R110, R111, R112

### 3. C03 serial-console-and-node-facts

Serial console to port 5000 of vrnetlab nodes through node_services.py (raw TCP with minimal telnet handling, same ticket and Origin rules), and a Container section in the device drawer (kind, image, container name and ID, state, uptime, addresses). No helper. About 4 h. LIVE: vJunos-switch (about 5 GB) to prove port 5000 is reachable from the host-network manager container and that a boot can be watched; XRv9k only if memory allows (16 GB).

Why this order: The highest-value student feature for slow VM nodes (see the boot, get in when SSH never comes up) that needs no privileged helper change. Live proof of the console port decides the design early, before the helper chunks.

Rows: R021, R024

### 4. C04 diagnostics-logs-and-interfaces

Three read-only, transient operations-helper actions and their UI: logs (docker logs tail, never persisted), interfaces (containerlab inspect interfaces) with an Interfaces section in the device drawer, containerlab version in capabilities; inspect table sorting, search, ports; stretch: bounded interface-stats sample.

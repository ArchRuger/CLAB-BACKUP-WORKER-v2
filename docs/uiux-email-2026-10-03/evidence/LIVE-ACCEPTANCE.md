5. Observation: unreachable device in the review step is a muted line, no failed badge; it shows the exception class name (SSHException).
6. Observation: the state pill and text both read "Unsaved changes" side by side (duplicate wording).
7. Observation: the lab page overflows horizontally at 390 px (header manager button, 430 px wide document).
8. Not done: poll-provoked re-announce check while an error summary is visible; close mid-run on the reachable all-device case (8 s run); Renumber and Remove design (not run); the apply path itself (deliberately not run).
